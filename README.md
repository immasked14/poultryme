# PoultryMe

Poultry e-commerce landing page (HTML/CSS/JS only).

## Features
- Hero, categories by age, product grid with search/filter/sort
- Product details modal, cart with localStorage
- Admin dashboard with CRUD (localStorage)
- Responsive layout

## Run locally
Open `index.html` in a browser. No build step required.

## Deploy
Push to GitHub and enable GitHub Pages from main branch root.
